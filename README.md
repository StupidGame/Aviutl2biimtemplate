# biimテンプレート for AviUtl2

AviUtl2のフィルタプラグインSDKで作った、biim形式の画面枠を出力するメディアオブジェクトです。
ゲーム欄は初期状態で透明なので、ゲーム映像へ右欄と下欄を重ねられます。
ゲーム欄と右下欄に使う動画・画像を選び、レイアウトへ自動配置する機能もあります。
複数素材は順番を編集して、同じ欄へ時間順に連続配置できます。
AviUtl2 2.1.2以降が必要です。

## インストール

`dist/BiimTemplate.au2pkg.zip` をAviUtl2のプレビュー画面へドラッグ＆ドロップします。

手動で入れる場合は、`dist/BiimTemplate.auf2` をAviUtl2のアプリケーションデータフォルダにある
`Plugin/BiimTemplate/` へコピーします。

## 使い方

1. AviUtl2のオブジェクト追加から「biimテンプレート」を追加します。
2. 必要な長さまでオブジェクトを伸ばします。
3. オブジェクト設定の「素材の追加・編集」ボタンを押すと、素材の追加・編集・配置を行う管理ダイアログが開きます。
   - 上部の「配置先」で「ゲーム欄」または「右下欄」を選びます。
   - 「素材を追加」を押して動画や画像ファイルを選択します（単一ファイル・複数ファイルどちらも選択可能）。
   - 一覧で素材を選択すると、下部の入力欄から素材の表示長さ（フレーム数）を直接変更して「長さを適用」できます。また、タイムライン上の開始〜終了フレーム範囲（例: `10-49F`）も確認できます。
   - 「タイムラインで選択」を押すと、選択した素材のオブジェクトにAviUtlのフォーカスを合わせ、タイムラインのカーソルと表示位置を該当素材の開始フレームへ直接ジャンプさせます。
   - 「ファイルを変更」で選択中の素材を別の動画・画像へ差し替えられます。
   - 「配置先を変更」で選択中の素材をゲーム欄と右下欄の間で移動できます。
   - 「上へ」「下へ」で再生順を並べ替えたり、「一覧から外す」で不要な素材を除外できます。
   - 「配置」を押すと、タイムラインの空きレイヤーへ素材オブジェクトが自動配置・更新されます。
4. オブジェクト設定の同期ボタンで、タイムライン編集と枠の長さをワンクリックで揃えられます。
   - 「長さを素材に合わせる」: タイムライン上で動画を途中で切ったり（分割）、トリム・伸縮・移動した場合に、配置されている素材（ゲーム欄・右下欄）のうち一番長い終端フレームに合わせてテンプレートの長さを自動調整します。
   - 「素材を枠の長さに合わせる」: テンプレート枠の長さに合わせて、素材クリップの終端を自動で揃えます。
5. オブジェクト設定で右欄と下欄の文章、背景色、幅、高さなどを編集します。

動画は元の再生時間、静止画は5秒を基準に順番どおり連結され、素材の追加・削除や長さの変更に合わせてテンプレートの長さもゲーム欄または右下欄の長い方に自動調整されます。
タイムライン上で素材を直接分割（途中で切る）したり、前後のトリムや削除を行っても、プラグインがレイヤー上の分割ピースをすべて自動認識します。「長さを素材に合わせる」を押すか、「素材の追加・編集」ダイアログで確定することで、テンプレートの長さも切った素材の終端へ自動で追従します。

既定の1280×720では、次の四分割になります。動画と画像は縦横比を維持し、欄内へ収まる大きさで中央配置されます。

| 場所 | 大きさ | 用途 |
| --- | ---: | --- |
| 左上 | 960×540 | ゲーム動画・画像 |
| 右上 | 320×540 | 解説、補足、進行情報 |
| 左下 | 960×180 | 話者名と字幕 |
| 右下 | 320×180 | 立ち絵、補助動画・画像 |

主な設定は次の通りです。

- レイアウト: 右欄の幅、下欄の高さ、余白、区切り線
- 動画・画像: 素材の追加・編集（ゲーム欄・右下欄の配置先切替、単一/複数選択、長さ編集、タイムライン選択、ファイル差し替え、欄移動、順番入替、いつでも追加・削除、自動配置）、「長さを素材に合わせる」、「素材を枠の長さに合わせる」、「右下欄を透過」
- 背景: 右欄・下欄・右下欄・ゲーム欄の色、背景の不透明度
- テキスト: 見出し、右欄本文、話者名、下欄本文、フォント、文字色、縁取り
- 「720p基準で拡縮」を有効にすると、余白や文字サイズを出力解像度に合わせて拡縮します
- 「ゲーム欄を塗る」を有効にすると、透明部分にも指定色を入れられます

### テキストの途中変更（字幕・見出し・話者名の動的切り替え）

下欄の本文（字幕）、話者名、右欄の見出し、右欄の本文は、再生の途中や区間に応じて自動で切り替えられます。

1. **区切り線（`---` または `===`）で区間ごとに切り替える**:
   - AviUtlのオブジェクト設定で「中間点」を追加すると、区切り線で分けたテキストが区間1、区間2、区間3...へ順番に適用されます。
   ```text
   最初の字幕です
   ---
   中間点以降の字幕です
   ---
   3番目の区間の字幕です
   ```
2. **フレーム数タグ（`[0F]`, `[60F]` など）で切り替える**:
   - 中間点を追加しなくても、指定したフレーム番号からテキストを自動で切り替えられます。
   ```text
   [0F] スタート時の字幕
   [60F] 60フレーム目からの字幕
   [120F] 120フレーム目からの字幕
   ```
3. **時間タグ（`[0:00]`, `[0:05]`, `[5s]` など）で切り替える**:
   - `[分:秒]` または `[秒数s]` を指定して時間指定で切り替えられます。
   ```text
   [0:00] 開始時の字幕
   [0:05] 5秒経過時の字幕
   [0:15] 15秒経過時の字幕
   ```
4. **字幕内で話者名を同時に切り替える**:
   - 下欄本文のタグに `[フレーム:話者名]` または `[時間:話者名]`、`[区間:話者名]` と書くことで、話者名欄も自動で連動して切り替わります。
   ```text
   [0F:ずんだもん] ずんだもんなのだ！
   [60F:四国めたん] めたんなのよ。
   [120F:ずんだもん] 掛け合いも1つのテキスト欄で簡単！
   ```
5. **タイムライン上での分割（クリップ切断）**:
   - テンプレートオブジェクトをタイムライン上で「分割」して、クリップごとに完全に独立したテキストや設定を持たせることも可能です。「長さを素材に合わせる」ボタンは同じレイヤーの末尾のテンプレートピースのみを素材終端へ延長するため、途中で切ったクリップが上書きされることなく安全に編集できます。

素材はテンプレートより背面の空きレイヤーへ置かれるため、区切り線や字幕欄より前へはみ出しません。
テンプレートが一番上のレイヤーにある場合は、素材用の背面レイヤーを確保するためテンプレート自身を下へ移動します。
右下欄へ素材を配置すると自動で「右下欄を透過」が有効になり、配置した素材が見えるようになります。手動での切り替えも可能です。
レイアウトの比率を変更した後は、以前の素材オブジェクトを削除して配置し直すと新しい欄へ合います。

## ビルド

Visual Studioの「C++によるデスクトップ開発」を入れたWindows環境で、PowerShellから実行します。

```powershell
.\build.ps1
```

生成物は `dist/` に出力されます。
DLLを読み込み、1280x720の既定レイアウトまで検査する場合は `.\build.ps1 -RunTests` を使います。

GitHub Actionsの「Build AviUtl2 plugin」は、`main`へのpush、Pull Request、`v`で始まるタグ、
手動実行でWindows x64版をビルドします。完了後のArtifactsから
`BiimTemplate-AviUtl2-x64`を取得できます。

ローカルに `aviutl2_sdk/filter2.h` があれば、そのSDKを参照します。SDKがない場合、または
`-DownloadSdk`を付けた場合は、[AviUtl公式サイト](https://spring-fragrance.mints.ne.jp/aviutl/index.php)から
2026年8月31日版のSDKを取得し、SHA-256を検証してからビルドします。SDK本体はリポジトリに含めません。
SDKのライセンス情報は `THIRD_PARTY_NOTICES.md` を確認してください。
