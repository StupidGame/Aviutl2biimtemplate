# biimテンプレート for AviUtl2

AviUtl2のフィルタプラグインSDKで作った、biim形式の画面枠を出力するメディアオブジェクトです。
ゲーム欄は初期状態で透明なので、ゲーム映像へ右欄と下欄を重ねられます。
ゲーム欄と右下欄に使う動画・画像を選び、レイアウトへ自動配置する機能もあります。
複数素材は順番を編集して、同じ欄へ時間順に連続配置できます。
AviUtl2 2.1.2以降が必要です。

## インストール

`dist/BiimTemplate.au2pkg.zip` をAviUtl2のプレビュー画面へドラッグ＆ドロップします。

手動で入れる場合は、`dist/BiimTemplate.auf2` をAviUtl2のアプリケーションデータフォルダにある
`Plugin/BiimTemplate/` へコピーします。

## 使い方

1. AviUtl2のオブジェクト追加から「biimテンプレート」を追加します。
2. 必要な長さまでオブジェクトを伸ばします。
3. オブジェクト設定の「素材を追加」ボタンを押すと、素材の追加と配置を行う管理ダイアログが開きます。
   - 上部の「配置先」で「ゲーム欄」または「右下欄」を選びます。
   - 「素材を追加」を押して動画や画像ファイルを選択します（単一ファイル・複数ファイルどちらも選択可能）。
   - 必要に応じて「上へ」「下へ」で再生順を並べ替えたり、「一覧から外す」で不要な素材を除外できます。
   - 配置先を「右下欄」に切り替えて、立ち絵や補助動画を追加することも可能です。
   - 「配置」を押すと、タイムラインの空きレイヤーへ素材オブジェクトが自動配置されます。
4. オブジェクト設定で右欄と下欄の文章、背景色、幅、高さなどを編集します。

動画は元の再生時間、静止画は5秒を基準に順番どおり連結され、必要ならテンプレートの終了位置も自動で伸びます。
すでに配置済みの素材がある場合も、いつでも「素材を追加」ボタンから現在の配置順を確認し、並べ替え・追加・除外を行ってタイムラインへ反映できます。

既定の1280×720では、次の四分割になります。動画と画像は縦横比を維持し、欄内へ収まる大きさで中央配置されます。

| 場所 | 大きさ | 用途 |
| --- | ---: | --- |
| 左上 | 960×540 | ゲーム動画・画像 |
| 右上 | 320×540 | 解説、補足、進行情報 |
| 左下 | 960×180 | 話者名と字幕 |
| 右下 | 320×180 | 立ち絵、補助動画・画像 |

主な設定は次の通りです。

- レイアウト: 右欄の幅、下欄の高さ、余白、区切り線
- 動画・画像: 素材の追加・管理（ゲーム欄・右下欄の配置先切替、単一/複数選択、順番入替、いつでも追加・削除、自動配置）、「右下欄を透過」
- 背景: 右欄・下欄・右下欄・ゲーム欄の色、背景の不透明度
- テキスト: 見出し、右欄本文、話者名、下欄本文、フォント、文字色、縁取り
- 「720p基準で拡縮」を有効にすると、余白や文字サイズを出力解像度に合わせて拡縮します
- 「ゲーム欄を塗る」を有効にすると、透明部分にも指定色を入れられます

素材はテンプレートより背面の空きレイヤーへ置かれるため、区切り線や字幕欄より前へはみ出しません。
テンプレートが一番上のレイヤーにある場合は、素材用の背面レイヤーを確保するためテンプレート自身を下へ移動します。
右下欄へ素材を配置すると自動で「右下欄を透過」が有効になり、配置した素材が見えるようになります。手動での切り替えも可能です。
レイアウトの比率を変更した後は、以前の素材オブジェクトを削除して配置し直すと新しい欄へ合います。

## ビルド

Visual Studioの「C++によるデスクトップ開発」を入れたWindows環境で、PowerShellから実行します。

```powershell
.\build.ps1
```

生成物は `dist/` に出力されます。
DLLを読み込み、1280x720の既定レイアウトまで検査する場合は `.\build.ps1 -RunTests` を使います。

GitHub Actionsの「Build AviUtl2 plugin」は、`main`へのpush、Pull Request、`v`で始まるタグ、
手動実行でWindows x64版をビルドします。完了後のArtifactsから
`BiimTemplate-AviUtl2-x64`を取得できます。

ローカルに `aviutl2_sdk/filter2.h` があれば、そのSDKを参照します。SDKがない場合、または
`-DownloadSdk`を付けた場合は、[AviUtl公式サイト](https://spring-fragrance.mints.ne.jp/aviutl/index.php)から
2026年8月31日版のSDKを取得し、SHA-256を検証してからビルドします。SDK本体はリポジトリに含めません。
SDKのライセンス情報は `THIRD_PARTY_NOTICES.md` を確認してください。
